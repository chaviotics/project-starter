# {{PROJECT_NAME}} — Session Log

This month's logged sessions, newest first. Each full entry is in `logs/` as
`YYYY-MM-DD-NN-slug.md`. Earlier months are in `logs/index-YYYY-MM.md`.

**Row budget: about 25 words in Summary.** Name what changed and where the detail
is. The reasoning, rejected options, and loose ends go in the linked log file.

**Log a session only when it made a decision, changed scope, or found something
that would cost time to rediscover.** A tweak (copy edit, spacing, a one-file fix)
gets a clear commit message and no row here.

**Month rollover:** the first session of a new month moves the previous month's
rows into `logs/index-YYYY-MM.md`, under a copy of the table header.

An index that grows past a screen or two stops being read. Without these limits,
a session index reached 80 KB in nine weeks.
