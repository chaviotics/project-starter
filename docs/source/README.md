# docs/source — drop the project's source material here

> **Stop if this folder is inside the starter's own repository.** If any folder
> above this one holds a `_project-starter/` folder, this is the master copy (or a
> copy made inside that repository). Copy the whole starter folder to where the
> project will live, rename it to the project slug, and drop files into **that**
> copy. Client material never goes into the starter's repository.

## What goes here

Anything the project starts from:

- the contract, TOR, SOW, or proposal
- the client's brief, and emails or call notes saved as text or PDF
- existing site content, product sheets, and spreadsheets
- brand assets, logos, mockups, screenshots, and reference sites (a text file of
  links is fine)
- **`kickoff-notes.md`**: your own notes. Fill it in even if the documents look
  complete, because they rarely say everything.

## Rules

- **Originals are never renamed, edited, moved, or deleted.** Derived documents
  such as `docs/sot.md` cite them by file name instead.
- Don't put passwords or API keys here. If a document contains some, setup flags
  it and never copies the value anywhere.
- Setup replaces this README with an index: one line per file, saying what it is
  and what it was used for.
