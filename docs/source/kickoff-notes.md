blank. Setup reads this first and asks only about what is still missing.

## Size: light or full?

Light means one codebase and weeks rather than months. Full means several phases
with separate sign-offs, months of work, or more than one codebase. Payment doesn't
decide size (a small site paid 50/50 is still light), and neither does an
undecided stack.

## Stack, hosting, domain: decided or preferred

## Repo and commands

Package manager (npm, pnpm…), the exact install / dev / build / lint / test
commands if known, default branch, and dev-server rules (ports, processes not to
kill). GitHub: which account or organization, repository name, private or public,
and the commit name and email. Documents rarely say any of this.

## Does it have a UI? Design direction, references, existing brand

## Must never happen

Examples: never invent prices, claims, or testimonials · no new paid services
without approval · WCAG AA · no new dependencies without approval.

## Waiting on others

Access, content, assets, approvals: what's needed and from whom.

## AI tools

Claude Code, Codex, or both? For a client project, do the terms permit each
vendor to process the client's material?
