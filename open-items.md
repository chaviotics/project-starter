# Open Items — {{PROJECT_NAME}}

Decisions and risks deliberately deferred, and questions asked but not yet
answered. Read before proposing work in an area an item touches. Review all of
them before any release or handover.

**Row budget: about 60 words.** State the item, why it waits, and what resolves
it. Link the detail (a log, a spec, a doc) instead of writing it here. A register
whose rows grow into essays stops being scanned.

**Numbers are permanent.** Add new items at the top with the next number. When an
item closes, move its row to `logs/open-items-closed.md` with `CLOSED YYYY-MM-DD`
and one clause on how it closed. Its number stays reserved, so references from
logs and commits still resolve.
